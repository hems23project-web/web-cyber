# public/photos — YOUR PHOTOS GO HERE

The site never invents photos. If a file below is missing it renders an
elegant placeholder that names the file it is waiting for, so nothing breaks
and nothing looks unfinished.

order, so `munroe.png` is fine too.

Nothing else needs changing. Commit the photos with the site so they deploy.
